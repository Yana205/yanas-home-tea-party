# yana's home tea party 🍵

A cozy one-page website for Yana's home café — Japanese tea and side sweets, served at a small table for a few guests at a time.

Built from the Claude Design project *Yana's Home Tea Party* and published as a static page with GitHub Pages.

## Deployment

Every push to `main` triggers the **Deploy to GitHub Pages** workflow ([.github/workflows/deploy.yml](.github/workflows/deploy.yml)), which uploads the repository as-is and deploys it to GitHub Pages.

## Notes

- Images in `uploads/` come from the design project's image slots.
